# FleetManager Server

FleetManager Server — веб-система для централизованного управления парком компьютеров и сетевых принтеров. Она объединяет сведения об устройствах, помогает отслеживать их состояние и выполнять задачи администрирования. Для сбора данных с Windows-компьютеров используется [FleetManager Agent](https://github.com/Xorizo-n/FleetManager-Agent).

## Компьютеры и инвентаризация

Реестр содержит сведения о компьютерах, их доступности, расположении и последнем обращении агента. Устройства можно объединять в группы, отмечать тегами, искать и фильтровать. Карточка компьютера собирает основные сведения, историю задач и обнаруженные проблемы.

Агент передаёт информацию об операционной системе, процессоре и памяти, сетевых адаптерах, дисках и установленном ПО. Система также показывает состав рабочего места: компоненты компьютера, мониторы и периферийные устройства. Изменения оборудования сохраняются в истории и могут сопровождаться уведомлениями.

Каталог программ помогает узнать, какие версии установлены и на каких компьютерах они встречаются. Отдельно отображаются заполненность дисков и сведения об активации Windows и Office.

## Сетевые принтеры

Реестр принтеров позволяет добавлять устройства вручную или находить их в подсетях с помощью компьютеров в аудиториях. Поиск запускается по расписанию и вручную; если выбранный компьютер недоступен, система пробует другие компьютеры той же аудитории. Для найденного устройства определяется предполагаемое расположение.

При опросе по SNMP отображаются доступность, модель, состояние, сообщения и ошибки, счётчик страниц и сведения о расходных материалах, если устройство их предоставляет. Имя принтера обновляется по данным устройства. Из списка можно открыть его веб-интерфейс.

## Удалённое управление и задачи

- Пробуждение компьютеров по сети и перезагрузка выбранных работающих устройств.
- Переход к подключению через удалённый рабочий стол.
- Запуск плейбуков Ansible на отдельных компьютерах и группах, в том числе по расписанию.
- Просмотр хода выполнения, результатов и истории задач.
- Редактирование плейбуков и управление установщиками для развёртывания программного обеспечения.
- Назначение обоев рабочего стола и экрана блокировки.

## Управление агентами

Сервер показывает установленные версии агентов и помогает находить компьютеры, которым требуется обновление. Обновление можно запустить удалённо; агент также поддерживает получение обновления через собственное соединение с сервером.
